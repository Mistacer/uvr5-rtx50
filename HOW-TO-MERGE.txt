安装包被拆成 2 个分卷（GitHub 单个 Release 资产上限 2 GB）。

第一步：把所有分卷下载到同一个文件夹。
第二步：在该文件夹打开 cmd 或 PowerShell，执行下面命令合并。

cmd：
    copy /b UVR5-5.6.0-Setup.exe.001+UVR5-5.6.0-Setup.exe.002 UVR5-5.6.0-Setup.exe

PowerShell：
    $parts = Get-ChildItem .\UVR5-5.6.0-Setup.exe.* | Sort-Object Name
    $out = [System.IO.File]::Create((Join-Path $PWD 'UVR5-5.6.0-Setup.exe'))
    foreach ($p in $parts) { $s = [System.IO.File]::OpenRead($p.FullName); $s.CopyTo($out); $s.Dispose() }
    $out.Dispose()

第三步：校验（对照 SHA256SUMS.txt）：
    Get-FileHash .\UVR5-5.6.0-Setup.exe -Algorithm SHA256
